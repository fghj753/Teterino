# Сайт автосервиса — деревня Тетерино

Адрес: Московская область, Можайский район, деревня Тетерино, 70Г.  
Телефон: +7 (926) 656-57-43. Ежедневно 08:30–17:30.

Лёгкий сайт на HTML, CSS, JavaScript и Node.js (версия 16+). Внешние npm-пакеты не нужны. Заявки через сайт отключены: посетители связываются с автосервисом по телефону. Услуга эвакуации удалена с сайта.

## Запуск

```sh
node server.js
```

Откройте `http://localhost:3000`. Порт можно изменить: `PORT=8080 node server.js`.

## Структура

- `server.js` — раздача статических файлов, защита путей, 404 и SEO-маршруты.
- `public/index.html` — содержимое страницы.
- `public/css/styles.css` — адаптивный дизайн.
- `public/js/app.js` — мобильное меню, FAQ и индикатор графика работы.
- `public/assets/images/` — фотографии для сайта.
- `public/assets/icons/favicon.svg` — иконка сайта.

## Изменение услуг

В `public/index.html` найдите раздел `id="services"`. Каждый пункт — отдельный блок `<li class="service">`. Добавьте или удалите нужный блок.

## Фотографии

Добавьте файлы в `public/assets/images/` и вставьте в HTML, например:

```html
<img src="/assets/images/service.jpg" alt="Автосервис" width="1200" height="800" loading="lazy">
```

## Публикация

1. Разместите папку проекта на хостинге с Node.js 16+.
2. Запустите `SITE_URL=https://ваш-домен.ru PORT=3000 node server.js`.
3. Для постоянной работы используйте pm2 или systemd.
4. Настройте HTTPS и проксирование на сервер.
5. Проверьте контактный телефон, адрес и график перед публикацией.
